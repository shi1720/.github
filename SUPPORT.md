# Support

Read the project's setup and status notes first. For public projects, open an issue with the repository version, runtime versions, steps to reproduce and a sanitized error message. For private projects, use an existing private collaboration channel.

Include what you expected and what you already tried. Remove API keys, personal information and customer data from logs and screenshots. Security reports belong in the private reporting process described in [SECURITY.md](SECURITY.md).

Historical prototypes may depend on external services or model versions that are no longer available. Their presence here is not a hosting or support guarantee.
